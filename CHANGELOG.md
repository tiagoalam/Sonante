# Changelog

## 0.7.2

- Add WavPack metadata and Local library support, including supported single-image and multi-file WavPack/CUE albums.
- Generalize the Navidrome integration into a Subsonic/OpenSubsonic source while preserving existing Navidrome connections.
- Add persistent personal Collections that can combine Local, Plex and Subsonic albums.
- Add the Discotheque album Carousel with keyboard navigation and source-aware album presentation.
- Add an About / Help dialog with separate About and keyboard-shortcut tabs.
- Improve Local metadata and artwork handling, source navigation and compatibility checks.

## 0.7.1

- Add a persistent SQLite catalog for local music and a manual import path for folders saved by earlier public versions.
- Add optional local LRC lyrics and online lyrics lookup with per-track source selection.
- Add local AutoEQ ParametricEQ import and a read-only OPRA headphone-profile browser.
- Improve library navigation, metadata diagnostics, artwork feedback, equalizer availability and Now Playing controls.

## 0.6.3

- Generate more varied smart-playlist previews while preserving filters, limits and queue state.
- Show online-artwork enrichment progress in the Albums header.
- Add contextual multi-track selection and improve navigation contrast.
- Surface current MPD playback errors while suppressing stale errors after successful playback.
- Keep Signal Path focused on route, format and observed-output details, without bit-perfect certification.
